# 股海小韭

一款在瀏覽器上就能玩的股市模擬遊戲。你是剛出社會的小韭，要在股海裡一邊工作、一邊投資，付得出每個月的帳單，並一路累積到「第一桶金」甚至「千萬富豪」。

## 遊戲特色

- **即時行情**：每 2 秒跳一次價格，大盤有多頭、空頭、盤整，還有漲跌停、開盤撮合等台股規則
- **完整交易**：現股、零股、融資、融券、ETF、定期定額、參加公開收購
- **研究公司**：月營收、季報、法說會、分析師評等、法人籌碼、內部人動向、現金股利
- **生活系統**：精力值、上班與打工、生活費與房租、遲繳三次就破產
- **兩種模式**：
  - 劇情模式：從 10 萬元開始，搭配像素動畫的主線劇情
  - 自由模式：從 50 萬元開始，專心玩股票
- **自動存檔**：存在瀏覽器裡，下次打開可以繼續

## 怎麼玩

直接用瀏覽器打開遊戲網址即可，不需要安裝。第一次開新局會有新手導覽，遊戲中也可以隨時點右上角的「說明」。
